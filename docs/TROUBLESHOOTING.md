# 문제 해결

[← README](../README.md)

| 증상 | 확인 방법 |
|---|---|
| python 명령을 찾지 못합니다. | Python 3.10 이상을 설치하고 Windows는 py, macOS·Linux는 python3 명령을 확인합니다. |
| 스킬이 목록에 보이지 않습니다. | SKILL.md가 스킬 폴더 바로 아래에 있는지 확인합니다. 새 대화를 열고 필요하면 앱을 다시 시작합니다. |
| 설치 시 기존 파일이 있다고 나옵니다. | 기존 스킬을 덮어쓰지 않도록 한 동작입니다. 설치 위치와 로컬 수정 여부를 확인합니다. |
| --update가 로컬 수정을 발견합니다. | 수정본을 별도로 보존한 뒤 새 버전과 병합합니다. 자동으로 삭제하거나 덮어쓰지 않습니다. |
| init 후 테마 파일이 없습니다. | init은 작업 폴더와 설정만 만듭니다. 원화와 네이티브 리소스를 구현한 뒤 빌드해야 합니다. |
| iOS 이미지 누락 오류가 납니다. | CSS의 이미지 이름과 Images/의 기본·@2x·@3x 파일 이름을 대조합니다. |
| Android 도구를 찾지 못합니다. | --sdk, --api, --build-tools, --java-home에 실제 설치 경로·버전을 넣었는지 확인합니다. |
| javac가 라이브러리를 찾지 못합니다. | 내장 빌더는 단순 Java 프로젝트용입니다. AndroidX·Kotlin 의존성은 원래 프로젝트의 빌드를 사용합니다. |
| 서명 비밀번호가 없다고 나옵니다. | 실행 환경에 THEME_STORE_PASSWORD를 준비합니다. 비밀번호를 GitHub 이슈나 명령 로그에 붙이지 않습니다. |
| ZIP이 이미 존재한다고 나옵니다. | 배포 버전을 덮어쓰지 않도록 한 동작입니다. 새 작업 버전이나 출력 경로를 사용합니다. |
| check는 성공했는데 화면이 이상합니다. | 파일 구조 검사와 시각 검수는 별개입니다. 미리보기와 실제 기기에서 말풍선·배경·글씨를 확인합니다. |
| 등록 자료는 있는데 업로드되지 않았습니다. | prepare는 오프라인 자료 생성입니다. 브라우저 연결과 플랫폼 로그인 후 업로드 스킬을 실행합니다. |
| 브라우저 연결이 시간 초과됩니다. | 도구의 연결 상태와 페이지 접근을 확인합니다. 페이지를 읽지 못한 경우 로그인 실패로 단정하지 않습니다. |
| submit_attempted에서 멈췄습니다. | 같은 상품 ID의 실제 접수 상태부터 확인합니다. 확인 없이 최종 버튼을 다시 누르지 않습니다. |
| 원스토어 심사는 접수됐지만 판매되지 않습니다. | 심사 접수·승인·판매 시작은 별개입니다. 원스토어 콘솔의 현재 상태를 확인합니다. |

오류를 제보할 때는 OS, Python 버전, 스킬 이름, 실행한 단계와 민감정보를 지운 오류 내용을 적어 주세요. 서명키·토큰·비밀번호·로그인 세션·구매자 정보를 올리지 마세요.

이 저장소의 작업 도구는 외부 터미널을 자동으로 열지 않습니다. AI 실행 환경 자체가 창을 표시하거나 포커스를 가져오는 경우에는 해당 환경의 설정과 도구를 확인해야 합니다.
