# 디자인과 검수 기준

## 캐릭터와 말풍선

다음 값은 귀여운 캐릭터형 테마의 출발점이며 카카오 공식 규격이나 모든 디자인의 강제 조건은 아니다. 사용자의 선택과 현재 프로젝트 구현을 우선한다.

- 캐릭터 장식 크기를 32pt 정도로 고정하고 본문 좌우 여백은 12pt 정도에서 시작한다.
- 받은 메시지는 왼쪽, 보낸 메시지는 오른쪽에 둔다. 글자의 세로 중앙은 장식과 투명 영역을 제외한 말풍선 본체를 기준으로 맞춘다.
- 한 글자 답장에서는 문장 길이에 맞춰 폭이 줄어들어야 한다. 장식 공간 때문에 긴 빈 영역을 만들지 않는다.
- 발신·수신의 표정이나 자세를 구분한다. 윗선 잡기, 모서리 턱괴기, 옆에서 안기, 위에 앉기, 뒤에서 빼꼼, 아래에 매달리기 등을 선택할 수 있다. 선택은 설정에 기록하고 빌드마다 바꾸지 않는다.
- 장식 크기·비율을 유지하고 늘어나는 것은 말풍선 본체가 되도록 만든다. 옆·아래 장식은 읽음 표시, 시간, 다음 메시지와 겹치지 않는지 확인한다.
- 배경 중심형에는 캐릭터를 억지로 추가하지 않는다. 수채화 등 질감은 사용자가 원하는 스타일일 때 적용한다.

## 필수 비교 장면

다음 문장을 보내기·받기·연속 메시지·선택 상태로 비교한다.

| 장면 | 예시 |
|---|---|
| 한 글자 | 응 |
| 짧은 답장 | 네! |
| 한 줄 | 오늘도 같이 놀자 |
| 긴 문장 | 작은 친구들과 함께하는 하루 |
| 여러 줄 | 편지를 가져왔어 / 반가워 |
| 큰 글씨 | 같은 문장을 접근성 글자 크기로 확인 |

확인할 항목은 본체 안의 세로 정렬, 좌우 여백, 문장 잘림, 장식과 텍스트의 겹침, 시간·읽음 표시, 이미지 왜곡이다. 빌드 도구는 이 시각적 항목을 자동 판정하지 않는다.

## 일곱 장의 미리보기

1. 표지는 테마명과 채팅·암호 화면을 보여 준다.
2. 암호 화면은 휴대전화 시스템 잠금화면과 구분한다.
3. 설치 안내는 iOS와 Android 절차를 구분한다.
4. 탭 아이콘은 기본·선택 상태를 모두 보여 준다.
5. 말풍선은 짧은 답장과 여러 줄을 포함한다.
6. 채팅 화면은 실제 읽을 수 있는 크기로 보여 준다.
7. 친구목록은 기본 프로필과 메뉴 색을 보여 준다.

모바일 표시 크기에서 제목과 안내가 읽히는지 확인한다. 실제 설치 리소스로 만든 예시는 그 사실을 표시하고, 카카오톡 실기기 캡처로 소개하지 않는다. 이미지 색상·기기별 화면 비율·폰트 차이를 검수 기록에 구분한다.
