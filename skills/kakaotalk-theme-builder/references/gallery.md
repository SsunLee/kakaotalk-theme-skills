# HTML 테마 보관함

테마 제작의 기본 결과물로 브라우저에서 볼 수 있는 HTML 보관함을 만든다. 사용자가 기존 보관함을 지정했거나 작업 자료에서 확인되면 실제 소스와 경로를 먼저 읽고 기존 디자인과 구조에 맞춰 갱신한다. 파일 검사·패키징만 요청한 경우에는 만들지 않는다. 특정 계정이나 사이트 주소를 임의로 정하지 않는다.

- 여러 테마는 모음 페이지에서 이름과 대표 이미지로 구분하고 각 상세 화면에 연결한다. 단일 테마는 상세 화면으로 충분하다. 기존 사이트가 있다면 기존 목록·모음·상세 페이지와 탐색 경로를 함께 갱신하고, 중복 항목이나 깨진 링크가 없는지 확인한다.
- 상세 화면에는 실제 테마 리소스에 맞는 대표 이미지와 잠금·채팅 등 미리보기, 테마명, 지원 기기와 확인된 설치 안내를 배치한다. 여러 이미지가 있으면 사용자가 선택해 볼 수 있도록 구성한다. 캐릭터 이미지 보관이 요청된 경우에는 확대 보기와 개별 저장·묶음 저장처럼 목적에 맞는 기능을 제공한다.
- 이미지와 파일은 올바른 상대 경로로 연결하고, 다운로드나 판매 링크는 확인된 대상과 공개 범위에 맞춘다. 비공개 보관함을 일반 구매자의 다운로드 경로로 대체하지 않는다. 구매자 전용 파일을 공개 보관함에 실수로 넣지 않는다.
- 모바일과 데스크톱에서 이미지 로딩, 글자 가독성, 탐색, 미리보기 선택, 필요한 다운로드·링크를 확인한다. 실제 확인한 범위와 미확인 항목을 구분한다. 보관함 미리보기를 실제 카카오톡 적용 검증으로 표시하지 않는다.
- 기본 산출물은 HTML과 관련 이미지·스타일·스크립트다. 실행 환경에 Sites나 아티팩트 같은 적합한 표시·공유 기능이 있으면 사용 가능 여부와 접근·공유 조건을 확인하고, HTML을 함께 안내하면서 필요한 경우 추천한다. 환경에 없는 기능을 사용 가능하다고 단정하지 않는다. 외부 공개나 기존 사이트 배포는 사용자의 요청 범위에 따른다.
