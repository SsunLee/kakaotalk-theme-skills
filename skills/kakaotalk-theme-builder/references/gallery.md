# HTML 테마 보관함 제작과 누적 갱신

테마 제작의 기본 결과물로 브라우저에서 볼 수 있는 HTML 보관함을 만든다. 기존 보관함이 있으면 그곳에 새 작업을 누적한다. 별도 HTML 파일을 만들었다는 이유만으로 기존 보관함 반영을 완료 처리하지 않는다. 파일 검사·패키징만 요청한 경우에는 만들지 않는다. 특정 계정이나 사이트 주소를 임의로 정하지 않는다.

## 기존 보관함부터 확인

작업 기록과 연결된 서비스에서 보관함 주소, 프로젝트 ID, 소스 위치, 배포 버전과 접근 범위를 찾는다. 확인 가능한 기록을 찾기 전에 사용자에게 주소를 다시 묻지 않는다. 로컬 소스가 현재 배포본과 같은 버전인지 확인하고 오래된 사본으로 최신 페이지를 덮어쓰지 않는다.

홈, 시리즈 모음, 개별 상세, 전체 목록·카탈로그, 다운로드 자료의 연결을 읽는다. 판매 자료 준비실이나 테마 스튜디오가 있으면 이번 변경과 연결되는 부분을 확인한다. 실제 경로·자료 ID·변경 파일·검증 결과는 해당 작업 폴더에 기록하고, 개인 주소나 계정을 이 공개 스킬에 고정값으로 넣지 않는다.

## 화면 구조와 자료 구분

기존 URL과 디자인을 유지하며 다음 역할을 연결한다. 아래는 화면의 역할이며 특정 폴더명을 강제하는 규격은 아니다.

| 화면 | 포함할 내용 |
|---|---|
| 보관함 홈 | 시리즈 대표 이미지, 제목, 실제 항목 수, 짧은 소개, 모음으로 가는 링크 |
| 시리즈 모음 | 항목별 이미지·이름·자료 종류와 상세 화면 또는 확대 보기 |
| 개별 상세 | 실제 자료의 미리보기, 지원 형식, 확인된 안내, 종류에 맞는 다운로드·판매 버튼 |
| 전체 목록 | 기존 검색·분류 규칙에 맞춘 새 항목과 상세 링크 |

여러 테마는 홈 → 시리즈 모음 → 개별 상세로 이어지게 한다. 캐릭터는 모음에서 확대 창으로 연결할 수 있다. 단일 테마를 위해 빈 모음 페이지를 만들지 않는다. 상세 화면에는 모음이나 보관함으로 돌아가는 경로를 제공한다.

| 자료 | 미리보기와 제공 파일 |
|---|---|
| 캐릭터 이미지 | 캐릭터별 확대 보기, 원본 PNG 개별 저장, 여러 종이면 묶음 저장을 제공한다. 투명 배경·픽셀 크기·형식을 실제 파일과 대조한다. |
| 설치형 카카오톡 테마 | 설치 리소스로 만든 잠금·채팅·말풍선·탭·친구목록 등 화면별 미리보기를 제공한다. 지원하는 iOS `.ktheme`, Android `.apk`, 안내서·배포 ZIP을 구분한다. |

캐릭터 PNG만 완성된 상태를 설치 가능한 테마로 표시하지 않는다. 준비되지 않은 설치 파일의 다운로드 버튼을 만들지 않는다. 테마 대표 이미지에는 이름과 실제 테마 화면이 명확히 보여야 한다. 확대 보기에서도 원본의 비율과 선명도를 유지하고 공개 저장이 허용된 자료만 제공한다.

## 관련 화면과 파일 함께 갱신

1. 기존 항목 ID 또는 새 고유 ID를 확인하고 이미지·설치 파일·안내서를 연결한다. 기존 URL과 ID를 이유 없이 바꾸지 않는다.
2. 홈 진입 항목, 시리즈 모음, 상세, 기존 전체 목록·검색 데이터를 함께 갱신한다. 같은 ID를 중복 추가하지 않고 시리즈·전체 항목 수를 실제 자료와 대조한다. 사용자가 지정한 위치를 따르며 그 외에는 기존 정렬 규칙을 유지한다.
3. 다운로드 목록이나 별칭을 쓰는 사이트라면 그 데이터도 갱신한다. 버튼의 파일명·형식·버전과 실제 다운로드 파일을 대조한다. 설치 파일과 ZIP은 가능한 경우 원본 해시와 비교한다.
4. 판매 등록도 요청되었으면 확인된 상품 URL·가격·공개 범위를 해당 항목에 연결한다. 기존 판매 자료 준비실·스튜디오가 이번 테마를 참조하면 필요한 데이터와 링크도 갱신한다. 관련 없는 기능을 새로 만들지 않는다.

## 표시 방식과 검증

- 이미지와 파일은 올바른 상대 경로로 연결하고, 다운로드나 판매 링크는 확인된 대상과 공개 범위에 맞춘다. 비공개 보관함을 일반 구매자의 다운로드 경로로 대체하지 않는다. 구매자 전용 파일을 공개 보관함에 실수로 넣지 않는다.
- 모바일과 데스크톱에서 이미지 로딩, 글자 가독성, 탐색, 미리보기 선택, 필요한 다운로드·링크를 확인한다. 실제 확인한 범위와 미확인 항목을 구분한다. 보관함 미리보기를 실제 카카오톡 적용 검증으로 표시하지 않는다.
- 기본 산출물은 HTML과 관련 이미지·스타일·스크립트다. 기존 보관함이 Sites에서 운영되면 같은 프로젝트와 주소를 우선 갱신한다. 새 보관함이나 다른 표시 방식이 필요할 때 이용 가능한 Sites·아티팩트를 확인한다. 지속적인 누적·공유에는 사이트를, 대화 안에서 개별 시안을 검토할 때는 아티팩트를 추천할 수 있다. 실제 기능과 접근·공유 조건을 확인하고 사용자의 선택을 따른다. 외부 공개나 배포는 요청 범위에 따른다.
- 홈에서 새 항목으로 들어가 모음·상세 화면을 열고 다시 돌아올 수 있는지 확인한다. 기존 항목도 유지되어야 한다. 확대 창은 닫기와 키보드 초점 복귀를 확인하고 해당 화면의 로딩·빈 목록·이미지 오류 상태도 검사한다.
- 개별 파일과 묶음 파일을 실제 내려받아 형식·내용·대상을 대조하고 판매 버튼의 목적지를 확인한다. 로컬 작성, 배포, 배포 화면 확인을 구분한다. 소스나 저장된 화면만 읽었으면 클릭·다운로드를 검증했다고 기록하지 않는다.
- 완료 보고에 보관함 위치, 추가·수정한 시리즈와 항목, 반영한 관련 화면, 수행한 검사와 미확인 사항을 적는다.
