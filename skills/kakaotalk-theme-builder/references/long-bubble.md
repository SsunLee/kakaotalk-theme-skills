# 길어지는 스타일 말풍선

사용자가 "길어지는 스타일", "늘어나는 말풍선", "캐릭터 몸이 길어지는", "롱바디", "몸통 말풍선"처럼 요청하면 이 분기로 만든다. 말풍선 자체가 캐릭터의 몸이다. 문장이 길어지면 몸통이 옆으로, 줄이 늘어나면 아래로 늘어나고 머리·귀·꼬리·발은 크기와 모양이 그대로다. 일반 말풍선 위에 캐릭터를 얹는 [기본 장식형](design-review.md)과 구분한다. 이런 요청이 없으면 이 분기를 쓰지 않는다. 기본값은 둥근 장식형이며, 캐릭터가 길쭉하게 생겼다는 이유만으로 AI가 이 스타일을 고르지 않는다.

## 두 가지 형태

| 형태 | 모습 | 어울리는 캐릭터 |
|---|---|---|
| 옆머리 몸통형 | 한쪽 끝에 얼굴, 반대쪽 끝에 꼬리나 엉덩이, 아래에 앞발·뒷발. 가운데 몸통에 글자가 들어간다. | 털이 많은 강아지, 고양이, 소시지형 동물 |
| 모서리 머리형 | 단색 둥근 사각형 몸통의 위쪽 모서리에 귀와 얼굴이 솟고, 반대쪽 아래 모서리에 꼬리가 나온다. | 검정 고양이처럼 몸 색이 단순한 캐릭터 |

사용자가 형태를 정하지 않으면 캐릭터 실루엣에 맞춰 하나를 추천하고 선택을 theme.json 또는 작업 기록에 남긴다. 빌드마다 바꾸지 않는다.

## 방향과 변형

- 기본 방향: 얼굴이 화면 가운데를 본다. 보낸 말풍선(오른쪽)은 얼굴이 왼쪽 끝, 받은 말풍선(왼쪽)은 얼굴이 오른쪽 끝이다. 사용자가 다른 방향을 정하면 그 선택을 따른다.
- 받은 말풍선이 단순 좌우 반전이면 `mirror_receive`로 만든다. 표정을 다르게 하려면 receive 원화를 따로 그린다. 반전하면 얼굴 속 글자나 비대칭 무늬가 뒤집히는지 확인한다.
- 01은 연속 메시지의 첫 말풍선, 02는 이어지는 말풍선이다. 기본은 둘 다 같은 캐릭터 전체로 하고, 사용자가 원하면 02에서 꼬리나 귀를 줄인다.
- 선택 상태(Selected)는 따로 그리지 않으면 본체를 약간 어둡게 만든다. iOS에만 쓰인다.

## 원화 규칙

카카오톡은 이미지를 3x3으로 나눠 가운데 띠만 늘린다. iOS는 캡 좌표의 1pt 한 줄만, Android 나인패치는 표시한 구간만 늘린다. 그래서 원화가 다음 조건을 지켜야 한다.

1. @3x 크기로 그린다. 가로·세로가 3의 배수면 @2x 변환이 정확하다. 예: 216×138px(72×46pt).
2. **가로 늘림 구간**: 몸통 가운데에 무늬 없는 구간을 6px 이상, 권장 15px 이상 둔다. 이 세로줄은 위 외곽선부터 아래 외곽선까지 모든 행이 같은 색이어야 한다. 눈·볼터치·발·꼬리·점무늬가 이 구간에 들어가면 늘어날 때 번진다.
3. **세로 늘림 구간**: 머리 아래, 발 위의 몸통 구간에 무늬 없는 행을 6px 이상 둔다. 여러 줄·세로로 긴 글에서 머리는 위에, 발은 아래에 남고 그 사이가 늘어난다. 옆머리 몸통형도 머리가 세로 늘림 구간 위에 완전히 들어가야 한다. 그래야 늘어난 왼쪽 가장자리가 몸통 외곽선으로 이어진다.
4. **글자 영역**: 머리·꼬리·귀·발을 뺀 몸통 안쪽이다. 늘림 구간은 글자 영역 안에 있어야 글자와 몸통이 함께 늘어난다. 옆머리형은 머리 쪽 여백이 크고 꼬리 쪽 여백이 작다.
5. **최소 크기**: 한 글자 답장일 때 말풍선 폭은 대략 머리+꼬리+글자 한 자다. 고정 부분이 크면 짧은 답장이 지나치게 길어지므로 머리 18~26pt, 꼬리 6~12pt에서 시작한다. 한 줄 높이는 머리·귀 높이와 발 높이를 합한 값보다 작아질 수 없다.
6. 몸통과 글자 대비를 확보한다. 검정·진한 몸통은 흰 글자, 흰 털 몸통은 진한 글자를 쓰고 text-color와 Android 말풍선 글자색을 함께 바꾼다.
7. 발과 꼬리가 시간·읽음 표시, 다음 말풍선과 겹치지 않도록 아래 장식은 4~6pt 안에서 끝낸다.

이미지 생성 도구에 요청하는 예시:

> 독창적인 캐릭터의 가로로 긴 몸통을 투명 배경으로 그려 주세요. 왼쪽 끝에 얼굴과 귀, 오른쪽 끝에 꼬리, 아래 양 끝에 작은 발이 있습니다. 가운데 몸통은 무늬 없이 한 가지 색이고 위아래 외곽선 두께가 일정해 말풍선처럼 가로·세로로 늘릴 수 있어야 합니다. 글자는 넣지 마세요. 정면에서 본 단순한 형태로 그려 주세요.

생성된 그림은 바로 쓰지 않는다. 투명 배경, 외곽선 두께, 늘림 구간의 균일함을 확인하고 필요하면 늘림 구간을 단색으로 정리한 @3x 원화로 다시 저장한다. 기존 유명 캐릭터나 다른 판매 테마의 모양을 복제하지 않는다.

## 도구로 리소스 만들기

설정 파일 예시 `long-bubble.json`(좌표는 @3x 픽셀, 끝값 포함):

```json
{
  "scale": 3,
  "stretch": {"x": [100, 120], "y": [78, 90]},
  "content": {"left": 78, "top": 36, "right": 33, "bottom": 30},
  "mirror_receive": true,
  "images": {
    "send01": "art/bubble-send01@3x.png",
    "send02": "art/bubble-send02@3x.png"
  },
  "per_image": {},
  "selected_darken": 0.85,
  "text_color": {"send": "#FFFFFF", "receive": "#FFFFFF"},
  "preview_background": "#EDEBE6"
}
```

- `images`에는 send01·send02·receive01·receive02와 `*_selected`를 지정할 수 있다. `mirror_receive`가 true이고 receive가 없으면 send를 반전한다.
- `per_image.<변형>`에 stretch·content를 넣으면 해당 원화만 다른 좌표를 쓴다.

```sh
python scripts/long_bubble.py build --spec long-bubble.json --project <작업폴더> [--apply-css] [--strict]
python scripts/long_bubble.py preview --spec long-bubble.json --out <작업폴더>/qa/long-bubble-preview.png --guides
```

build는 다음을 만든다.

- iOS `ios/Images/chatroomBubble{Send,Receive}{01,02}[Selected]@3x.png`, `@2x.png`
- Android `android/src/main/theme/drawable-xxhdpi/theme_chatroom_bubble_{me,you}_{01,02}_image.9.png`. 위·왼쪽 표시는 늘림 구간, 아래·오른쪽은 글자 영역이다.
- `qa/long-bubble-css.txt`: 캡 좌표(pt)와 `-ios-title-edgeinsets`(위, 왼쪽, 아래, 오른쪽). `--apply-css`를 쓰면 프로젝트 CSS의 MessageCellStyle-Send·Receive 블록에서 해당 줄만 바꾸고 글자색 줄은 유지한다.
- `qa/long-bubble-report.json`: 변형별 좌표, 반전 여부, 선택 상태 생성 방식, 경고.

늘림 구간에 무늬가 있거나 가로 늘림 줄이 완전히 투명하면 경고한다. 경고가 있으면 원화를 고친다. `--strict`는 경고가 있을 때 종료 코드 1을 돌려준다. Pillow가 필요하다(`python -m pip install Pillow`).

## 검수

preview는 [필수 비교 장면](design-review.md#필수-비교-장면)의 응·네!·한 줄·긴 문장·여러 줄과 세로로 긴 글(오/오/오/오/오)을 기본·큰 글씨로 보내기와 받기 양쪽에 그린다. `--guides`는 글자 영역을 분홍 선으로 표시한다. 다음을 직접 열어 확인한다.

- 머리·꼬리·발의 비율이 모든 장면에서 같고 몸통만 늘어나는지
- 한 글자 말풍선이 너무 길지 않은지, 세로로 긴 말풍선에서 머리가 위에 남고 몸통 외곽선이 끊기지 않는지
- 글자가 얼굴·꼬리·발과 겹치지 않고 몸통 세로 가운데에 오는지
- 받은 말풍선의 얼굴 방향과 표정이 의도대로인지

이 미리보기는 같은 원리로 늘린 시뮬레이션이다. 카카오톡 실제 화면, 기종별 글꼴·줄 간격과 구분해 기록한다. 테마 미리보기 7장 중 말풍선·채팅 화면에는 짧은 답장, 긴 문장, 세로로 긴 말풍선을 함께 보여 준다.
