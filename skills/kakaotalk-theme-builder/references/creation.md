# 원화에서 설치 파일까지

## 1. 기존 자료 확인

새 작업 폴더를 정하고 기존 원화, 생성 기록, theme.json, iOS 폴더, Android 소스, 설치 파일과 검수 결과를 먼저 읽는다. 사용자 고유의 경로·이름·판매 설정을 다른 프로젝트에 복사하지 않는다. 수정은 원본의 복사본이나 버전별 폴더에서 진행한다.

처음이라면 theme_tools.py init으로 작업 틀을 만들고 author와 description을 채운다. package에는 실제 배포용 고유 ID를 쓴다. com.example로 시작하는 예시 ID를 그대로 판매용으로 사용하지 않는다. 하나의 프로젝트 폴더는 하나의 테마 버전을 나타낸다.

## 2. 원화와 리소스 기획

캐릭터형, 말풍선 모양형, 배경 중심형 중 사용자의 목적에 맞게 선택한다. 캐릭터형이라면 얼굴, 발신·수신 표정, 앉은 모습, 탭 아이콘, 암호 화면 장식을 같은 얼굴·색·비율로 만든다. 한 장의 아틀라스를 쓰면 셀별 의미와 자르기 좌표를 기록하고 배경을 투명하게 보존한다.

예시 이미지 생성 요청:

> 독창적인 캐릭터의 투명 배경 리소스 시트를 만들어 주세요. 정면 얼굴, 발신 표정, 수신 표정, 앉은 모습, 친구·채팅·더보기 메뉴용 동작을 각각 분리해 주세요. 캐릭터의 비율과 색은 동일하게 유지하고 셀 사이에 충분한 여백을 주세요. 이미지 안에는 글자를 넣지 마세요.

배경은 별도로 만든다. 채팅 글자가 있는 상단·중앙은 읽기 쉬운 대비를 유지하고 원본의 가로세로 비율을 보존한다. 이미지 생성 도구가 없다면 기존 허가된 원화를 구현하는 단계까지만 진행한다.

## 3. 네이티브 리소스 구현

카카오 공식 안내에서 해당 버전의 iOS·Android 테마 가이드와 샘플을 확인한다. 설치 파일만 있고 편집 가능한 소스가 없으면 소스 복구 범위와 권리를 확인한다. 가이드가 오래되었다면 그 날짜와 실제 적용 확인 여부를 함께 기록한다.

- iOS: 공식 샘플의 CSS 블록과 리소스 키를 유지하고 이름·제작자·테마 ID·색상·이미지를 변경한다. 이미지 이름과 @2x/@3x 배율, 말풍선 stretch 좌표와 edge inset을 함께 관리한다. CSS 이름은 사용 중인 공식 샘플에 맞춘다. 제공 도구는 KakaoTalkTheme.css 또는 KakaoTalk.css 중 한 파일을 허용한다.
- Android: 패키지, 버전, 테마 인식용 metadata·permission, colors·styles·drawable 리소스를 샘플과 대조한다. Java Activity가 참조하는 R과 실제 리소스 이름을 일치시킨다. 사용자 선택 없이 광고·결제·데이터 수집 SDK를 추가하지 않는다.
- 나인패치: Android .9.png의 투명 테두리, 늘어날 영역과 내용 영역을 따로 설계한다. 캐릭터가 있는 부분을 늘림 영역에 포함하지 않는다. iOS의 늘림 기준과 본문 여백도 같은 의도로 맞춘다.

공식 샘플 다운로드는 에이전트가 현재 페이지에서 확인한 링크를 사용한다. 제3자 코드·폰트·원화의 이용조건은 각각 확인하며 SDK나 공식 샘플을 이 저장소에 재배포하지 않는다.

## 4. 미리보기와 검수

preview 7장을 작성하고 실제 PNG를 열어 확인한다. 화면을 본 적 없이 생성 성공 로그만으로 시각 검수를 완료 처리하지 않는다. 미리보기의 캐릭터·말풍선·배경은 설치 파일과 같은 원본을 사용한다. 개인정보가 담긴 실제 대화를 공개 미리보기에 사용하지 않는다.

파일 검사는 도구가 수행하지만 실제 기기 적용은 별도다. 설치한 Android 테마 앱의 자체 미리보기, 렌더링한 채팅 예시, 카카오톡에 실제 적용한 화면을 서로 구분한다. review.kakaotalk_tested는 실제 적용했을 때만 true로 기록하고 기기·OS·카카오톡 버전과 날짜를 qa/에 남긴다.

## 5. 배포

설치 파일과 안내서만 구매용 ZIP에 포함한다. 미리보기는 ZIP과 별도로 제공된다. 서명키·로그인정보·원화 원본·소스 코드는 판매 패키지에 자동으로 넣지 않는다. 판매용 라이선스와 환불 문구는 상품·플랫폼에 맞게 별도로 작성한다.

보관함 연결은 사용자가 지정한 경우에 수행한다. 비공개 보관함의 링크를 일반 구매자의 다운로드 링크로 쓰지 않는다. 실제 내려받은 파일의 해시를 원본과 대조한다.
