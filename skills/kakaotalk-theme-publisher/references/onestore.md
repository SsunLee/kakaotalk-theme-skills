# 원스토어 등록

## 준비

본인 개발자·판매자 계정, 고유 패키지 ID, 서명된 Android APK, 앱 아이콘, 대표 그래픽, 실제 앱 실행 화면, 상품 설명·문의처를 준비한다. 최소 OS·대상 SDK·이미지 크기·파일 요건은 현재 콘솔과 공식 문서에서 확인한다. 과거 작업의 고정 버전이나 이미지 크기를 최신 심사 요건이라고 표현하지 않는다.

빌더가 남긴 android-signature.json의 해시와 APK를 대조하고 필요하면 apksigner로 다시 검증한다. APK 서명 성공과 실제 설치·실행, 카카오톡 내부 테마 적용을 각각 구분한다.

## 실행

1. 상품 목록에서 이름과 패키지를 검색한다. 같은 상품이 있으면 기존 ID를 사용한다.
2. 신규 등록이 필요하면 앱 유형·언어·패키지·상품명을 현재 기능에 맞게 입력한다. 생성 직후 상품 ID를 기록한다.
3. 원본 APK를 업로드하고 패키지·버전·서명 검증 결과를 재조회한다. 기존 앱 업데이트라면 배포 중인 서명키와 버전 증가 조건을 유지한다.
4. 아이콘·대표 그래픽·서로 다른 실제 앱 실행 캡처를 넣는다. 이미지 사이에 업로드 완료를 확인하고 저장된 이미지 URL과 내용을 대조한다.
5. 지정 가격·배포 국가·개발자 연락처·기능 설명을 저장한다. 국내 판매 요청을 모든 국가 배포로 확대하지 않는다.
6. 이용등급 설문은 현재 질문과 앱 기능을 읽고 답한다. 기존 상품의 인증서를 다른 패키지에 복사하지 않는다. 자동으로 특정 등급이 나온다고 가정하지 않는다.
7. 심사 통과 후 자동 판매 또는 수동 판매는 사용자 요청에 맞춘다. 가격·국가·등급·APK·검증 참고사항을 다시 확인한다.
8. attempt 기록 후 심사를 한 번 요청한다.
9. 같은 상품 ID의 검증 현황과 요청 히스토리에서 접수를 확인한 뒤 review_requested로 기록한다. 검증중을 판매중으로 보고하지 않는다.

스크린샷이 테마 앱 자체의 미리보기라면 그렇게 설명한다. 카카오톡에 실제 적용하지 않았다면 카카오톡 내부 적용을 확인했다고 쓰지 않는다. 공통 반려 사유가 확인되면 같은 문제가 있는 다음 상품을 그대로 반복 제출하지 않는다.
