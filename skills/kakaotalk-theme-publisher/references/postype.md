# 포스타입 등록

## 공개 조건

테마마다 별도 글과 상품 ID를 만든다. 각 글에는 해당 테마의 미리보기와 iOS·Android 파일만 넣는다. 사용자가 묶음 판매를 명시하지 않으면 여러 테마를 한 유료 영역에 합치지 않는다. 가격 n원은 각 상품의 가격이며, 전체 묶음 가격으로 해석하지 않는다.

판매 가격과 무료 제공 조건은 별개다. 일반 공개·일반 채널 구독자 공개·포스트 구매자 공개·유료 멤버십 공개를 구분하고, 일반과 구독자 중 사용자가 지정한 무료 대상을 적용한다.

| 사용자 요청 | 처리 |
| --- | --- |
| “7일간 무료로 해주세요”처럼 단순 무료 요청 | 무료로 등록한다. 종료 후 유료 전환·비공개·삭제를 임의로 추가하지 않는다. |
| “3일간 구독자에게 무료로 해주세요”, 종료 후 조건 없음 | 발행 전에 “3일 후 유료로 전환할까요, 무료로 유지할까요?”를 묻는다. 유료라면 각 상품 가격도 확인한다. |
| “3일간 구독자 무료, 이후 각각 1,000원” | 각 테마별로 구독자 무료 3일과 이후 각 1,000원 조건을 적용한다. 이미 명시된 종료 후 처리와 가격을 다시 묻지 않는다. |
| 기간 없는 구독자 전용 무료 | 일반 채널 구독자 대상으로 0원 설정을 적용한다. |

1,000원과 3일은 위 예시의 조건이며 다른 요청의 기본값이 아니다.

기간 무료는 포스타입 자체 기간 무료 기능을 우선 확인한다. 사용자가 외부 예약 작업으로 처리하라고 지정하면 그 방식으로 진행한다. 실제 화면에서 무료 대상, 시작·종료 시각과 시간대, 종료 후 상품별 가격·공개 범위를 확인하고 기록한다. 유료 상품의 일시 무료 혜택을 영구 0원 상품과 혼동하지 않는다. “3일 후 유료”는 종료 후 구매 가격을 뜻하며 기존 이용자에게 자동으로 청구한다는 뜻이 아니다.

현재 계정에서 기간 무료 설정 위치나 동작을 확인하지 못했다면 관련 공식 안내와 실제 화면을 더 확인하고, 필요한 메뉴 위치만 사용자에게 질문한다. 초안과 파일 준비는 계속한다. 기능이 없다고 단정하거나, 승인 없이 외부 예약으로 대체하지 않는다. 사용자가 예약 처리를 승인한 경우에는 각 글을 지정된 무료 대상에게 발행하고, 발행 시각 기준의 무료 종료 시각에 같은 글 ID의 가격·공개 범위를 지정 조건으로 변경하는 일회성 예약을 등록한다. 예약에는 상품 ID, 종료 시각과 시간대, 상품별 가격, 변경할 공개 범위, 검증 절차를 명시한다. 예약 ID·활성 상태·다음 실행 시각을 재조회하고 실제 전환 실행과 예약 등록을 구분해 보고한다. 예약 실행에 필요한 앱 연결과 로그인 유지 조건을 안내한다. 유료 전환 요청을 비공개 전환·삭제로 바꾸지 않는다. 종료 시각과 유료 복귀가 실제로 저장됐다는 근거 없이 자동 전환 완료라고 보고하지 않는다. 소장본 열람 기간과 예약 발행은 무료 제공 종료 설정이 아니다.

발행 전 상품별로 테마명·포스트 ID·첨부 파일·기본 가격·무료 대상·시작/종료 시각·종료 후 가격 및 공개 범위·자동 전환 설정 근거를 대조한다. 본문 안내도 저장된 조건과 일치시킨다.

## 글 구성

짧은 소개 → 충분한 미리보기 → 운영체제별 다운로드 → 설치 방법 순서로 작성한다. 같은 안내를 여러 번 반복하거나 내부 검증 로그를 본문에 넣지 않는다. 무료 글에는 긴 유료 환불 규정을 넣지 않는다. 유료 글은 최신 플랫폼 정책과 실제 판매 조건을 확인해 안내한다.

## 실행

1. 대상 채널과 기존 글 목록을 확인하고 중복을 검색한다.
2. 제목·소개·미리보기 7장을 넣고 각 이미지가 끝까지 업로드되었는지 확인한다.
3. .ktheme와 .apk를 운영체제별로 첨부한다. 파일명·크기와 원본을 대조한다. 파일 확장자가 막히면 플랫폼에서 허용한 ZIP 형식으로 준비하고 안내를 수정한다.
4. 구독자 제한·구매 제한이 필요한 파일은 제한 영역 안에 둔다. 공개 소개 문단에 직접 다운로드 URL을 노출하지 않는다.
5. 상품별 가격·무료 대상·기간·종료 후 처리·공개 범위·대상 채널·썸네일을 확인하고 초안 ID를 기록한다. 요청받지 않은 시리즈·멤버십을 새로 만들지 않는다.
6. attempt 기록 후 발행 버튼을 한 번 누른다.
7. 같은 글 ID의 공개 설정과 첨부 파일을 재조회한다. 가능한 경우 비구독자 상태에서 다운로드가 제한되는지도 확인한다. 판매자 본인 화면만 보았다면 비구독자 접근 검증 완료라고 말하지 않는다.
8. 실제 공개 URL과 저장된 조건을 근거로 confirm한다.

이미 발행된 글의 수정은 같은 ID에서 수행한다. 가격·공개 시각·소장본 열람 조건은 사용자 요청 범위 안에서 변경한다. 로그인·추가 인증이 필요하면 해당 단계와 초안 ID를 보존한다.
