# 포스타입 등록

## 공개 조건

사용자가 구독자 전용 무료라고 요청했다면 일반 채널 구독자를 대상으로 0원으로 설정한다. 유료 멤버십·포스트 구매자 전용으로 바꾸지 않는다. 일반 공개 무료는 public, 유료 포스트는 buyers와 지정 가격으로 준비한다. 실제 편집기에서 해당 설정이 정확히 저장되었는지 확인한다.

## 글 구성

짧은 소개 → 충분한 미리보기 → 운영체제별 다운로드 → 설치 방법 순서로 작성한다. 같은 안내를 여러 번 반복하거나 내부 검증 로그를 본문에 넣지 않는다. 무료 글에는 긴 유료 환불 규정을 넣지 않는다. 유료 글은 최신 플랫폼 정책과 실제 판매 조건을 확인해 안내한다.

## 실행

1. 대상 채널과 기존 글 목록을 확인하고 중복을 검색한다.
2. 제목·소개·미리보기 7장을 넣고 각 이미지가 끝까지 업로드되었는지 확인한다.
3. .ktheme와 .apk를 운영체제별로 첨부한다. 파일명·크기와 원본을 대조한다. 파일 확장자가 막히면 플랫폼에서 허용한 ZIP 형식으로 준비하고 안내를 수정한다.
4. 구독자 제한·구매 제한이 필요한 파일은 제한 영역 안에 둔다. 공개 소개 문단에 직접 다운로드 URL을 노출하지 않는다.
5. 가격·공개 범위·대상 채널·썸네일을 확인하고 초안 ID를 기록한다. 요청받지 않은 시리즈·멤버십을 새로 만들지 않는다.
6. attempt 기록 후 발행 버튼을 한 번 누른다.
7. 같은 글 ID의 공개 설정과 첨부 파일을 재조회한다. 가능한 경우 비구독자 상태에서 다운로드가 제한되는지도 확인한다. 판매자 본인 화면만 보았다면 비구독자 접근 검증 완료라고 말하지 않는다.
8. 실제 공개 URL과 저장된 조건을 근거로 confirm한다.

이미 발행된 글의 수정은 같은 ID에서 수행한다. 가격·공개 시각·소장본 열람 조건은 사용자 요청 범위 안에서 변경한다. 로그인·추가 인증이 필요하면 해당 단계와 초안 ID를 보존한다.
