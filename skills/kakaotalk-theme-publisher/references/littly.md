# 리틀리 등록

1. 사용자가 지정한 리틀리 계정과 편집 페이지를 확인한다. 상품 목록에서 같은 이름과 기존 판매 주소를 검색한다.
2. 판매자 정보·수익계좌가 필요한 상태인지 확인한다. 다른 사람의 정보로 채우거나 판매 가능한 상태로 추정하지 않는다.
3. 디지털 파일 상품에 해당 테마의 구매용 ZIP을 첨부한다. 비공개 보관함 링크를 구매 파일 대신 쓰지 않는다.
4. 표지와 상세 미리보기 7장을 업로드하고 description.md를 상품 설명에 반영한다. 상대 이미지 경로는 실제 첨부 이미지로 대체한다.
5. 정확한 상품명·가격·파일명을 저장하고 구매 완료 메시지에 간단한 설치 안내를 넣는다. 상세페이지에서 저장 완료를 확인한다.
6. 초안 ID를 기록한다. 최종 노출·게시 동작 전에 사용자 요청 범위와 파일·가격을 확인하고 attempt를 기록한다.
7. 공개 주소에서 상품명·가격·상세 이미지·구매 진입을 확인하고, 새로고침 뒤 저장이 유지되는지 확인한다. 무료 설치 파일 링크가 의도치 않게 본문에 공개되지 않았는지 검사한다.
8. 결제하지 않았다면 실제 결제와 결제 후 자동 파일 전달은 미검증으로 보고한다.

그룹 추가나 정렬 변경은 사용자가 요청한 경우에 수행한다. 연결 대상은 실제 판매 URL이며 소유자 전용 보관함 URL이 아니다. 업로드가 403 등을 반환하면 일일 한도라고 단정하거나 우회하지 말고 관찰한 오류와 현재 첨부 상태를 보존한다.

공식 서비스: https://litt.ly/ . UI 이름과 조건은 현재 계정의 실제 화면에서 확인한다.
